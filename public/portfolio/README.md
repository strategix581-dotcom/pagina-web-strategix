# Strategix portfolio media

Place approved portfolio assets in the matching folder:

- `restaurants/`
- `beauty/`
- `clinics/`
- `dental/`

Use optimized `.webp` or `.jpg` files for photos and web-ready `.mp4` files
for video. After adding an asset, register it in `lib/industryPortfolio.ts`.
Until then, the site deliberately displays translated “coming soon” cards.
